Markdown

用纯文本写结构，渲染成 HTML；文档与代码终于能放在同一个仓库。

设计者John Gruber
诞生地美国
首次发布2004

01

语言档案Dossier

Markdown 由 John Gruber 在 2004 年发布，Aaron Swartz 参与了早期设计。它用少量符号（#、*、-、[]()）表示标题、强调、列表与链接，目标是「可读的纯文本」。

Markdown 的解析器把文本变成 AST，再渲染成 HTML。CommonMark 在 2014 年统一了语法细节；GitHub Flavored Markdown 增加了表格、任务列表与删除线；MDX 允许在文档里直接写组件。

它成了 README、文档站、博客与 issue 的默认格式。产物可以是 HTML、PDF、幻灯片，或一个静态站点。

Markdown 的设计目标是「不渲染也能读」。源文件本身就是一份可读的纯文本。

体积与形态 · 对数尺度示意

Markdown≈ 40 B
AST≈ 8 个节点
HTML≈ 70 B
页面≈ 2 KB
站点视项目而定
  1. 纯文本：可 diff、可合并、可搜索。
  2. AST：解析器把文档变成树，便于转换与扩展。
  3. HTML：浏览器能直接渲染，也能转 PDF/Docx。
  4. 静态站点：文档与代码同仓库，构建即发布。
