实测范围Scope

实测对象是每门语言的 Hello 程序与最基本的产物（源码 → 编译/运行 → 输出/目标文件）。它验证的是「这条链在本机跑得通」，不是对页面中每个示意地址、偏移或字节数的背书。

平台差异会被明确记录：例如 Windows/MinGW 的 C/C++ 产物是 PE/COFF，而页面中的 ELF 样例是 Linux 口径；Shell 实测使用 Git Bash 而非 WSL。未安装工具链的语言不写入实测记录。
