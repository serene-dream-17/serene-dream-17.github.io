怎么读How to read

横轴是首次发布年份，纵轴按「创世纪 / 系统 / 个人电脑 / 互联网 / 托管运行时 / 现代工程化 / 新一波 / 领域 / 标记」分带。节点颜色表示家族；曲线表示 lineage.from / to 中能映射到站内条目的影响关系。

这不是完整的学术谱系：只收录本站 78 个条目之间的边，非语言来源（如 λ 演算、汇编、数学记法）不会画成节点；同名不同义的条目也不会强行连线。

谱系基于各语言页的「源自 / 影响」字段；年代为首次发布年，不同资料的诞生年口径可能不同。最后核对 2026-10-28。
